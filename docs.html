Documentation

Guides and notebooks

Each guide is a Markdown document whose code runs in the test suite, and a Jupyter notebook generated from it with its outputs and interactive plots. The notebook links open in nbviewer, which renders the Plotly figures interactively; GitHub's own viewer shows the static copies saved with them. The tables are generated from the documentation index.

spynach

Read in order for a tour: Hilbert space first, then Liouville space; the solid-state, relaxation and spinning guides each add one ingredient; the pulse-sequence guide puts them together. Coming from Spinach is the reference for what carries over and what differs.

EasySpin port

EPReasy

The foundation guide covers spin systems, operators, Hamiltonians, energy levels, resonance fields, line shapes and grids; the simulators guide runs every simulator on a nitroxide and a few other systems. Coming from EasySpin is the reference for what carries over, what differs and what is not ported.

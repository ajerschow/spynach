Try it

Spynach, EasySpyn and ctps running in Pyodide. Pick an NMR, EPR or pathway example, edit it, run it. Every calculation goes to a web worker, so the page stays responsive.

Starting…

This page needs a web server rooted at the repository, not a file:// address, so the worker and the page scripts can load. Run python3 -m http.server in the repository folder and open http://localhost:8000/try.html.

Ctrl+Enter runs. show_spectrum, show_fid and show_image draw on the right; an easyspyn spectrum can be passed as is, and EPR axes run left to right. The 12800-orientation powder is the slow one, about a minute; the 1600-point powder, magic-angle spinning and the fit take a few seconds. Grid names such as leb_2ang_rank_17 are loaded from src/spynach/grids. A link such as try.html#ex-epr-hyscore opens and runs one example. Prefer GUI shows the main settings of an example as a form, with units and a description for each, and Prefer code goes back; an edit in the form rewrites the number in the code, and an edit in the code updates the form, and a parameter the code no longer uses is greyed out. If you rewrite the code until no parameter lines are left, Restore example brings the original and its form back, as does reloading the page. ?view=params opens the form.

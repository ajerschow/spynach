Quick install

Python 3.11 or newer

# NMR: ported as Spynach (including ctps)
pip install spynach

# EPR: ported as EasySpyn simulators
pip install easyspyn

# Symbolic: SpynDynamica, the SpinDynamica port
pip install spyndynamica

All three are on PyPI as separate distributions. Spynach and EasySpyn install Numba, which speeds up their kernels; SpynDynamica needs NumPy, SciPy and SymPy only. More install options

Spinach port

spynach

The Spinach spin dynamics kernel in Python, stage by stage, with Spinach's names, parameters and tolerances.

Liquid-state NMR in Hilbert and Liouville space, restricted bases, anisotropic interactions with powder averaging, Redfield relaxation, magic angle spinning, COSY, NOESY and HSQC. Verified against Spinach 2.13 at every stage.

EasySpin port

easyspyn

The simulators of EasySpin in Python, with EasySpin's interface: spin systems as dicts with EasySpin's field names, mT and MHz.

cw EPR of powders, crystals and solutions, least-squares fitting, ENDOR, magnetometry, slow motion, and pulse EPR (ESEEM, HYSCORE, Mims ENDOR). Verified against EasySpin 6.0.15 on every simulator.

SpinDynamica port

spyndynamica

SpinDynamica's symbolic and numerical spin dynamics in Python, with SpinDynamica's conventions: operators with SymPy coefficients, spins numbered from 1.

Product and spherical tensor operators, rotations and closed-form evolution, bases and superoperators, pulse sequences, signals and spectra, COMPUTE, adiabatic events, chemical exchange, symmetry and Lie algebras. Verified against SpinDynamica 3.10.2 on 976 reference cases.

Extras

ctps and tooling

What originated here: coherence transfer pathway selection with phase cycles, gradients and non-ideal pulses, cogwheel cycle search, relaxation pathways resolved by mechanism, and the verification tooling behind the ports.

Every pathway a sequence allows, ranked and drawn in an interactive explorer; parity harnesses and timed comparisons against MATLAB; executable guides; this browser playground.

What is here ctps guide Run an example

No MATLAB licence needed. Pip-installable packages that slot into the scientific Python stack, run on any machine, in Colab, or in this browser.

Verified, not eyeballed. Every ported stage is compared with reference data computed by Spinach, EasySpin or SpinDynamica itself, with tolerances that are stated, measured and published.

Readable kernels, ready for accelerators. The algorithms in plain Python with NumPy and SciPy, hot loops behind one backend adapter, and documentation whose code runs in the test suite.

Install

Install

Python 3.11 or newer. The three packages are separate distributions on PyPI: spynach is the NMR package with ctps, easyspyn the EPR package, spyndynamica the symbolic one (spynach[epr] installs the first two together). Numba comes with Spynach and EasySpyn, threading the sparse kernels of Spynach and compiling EasySpyn's (SPYNACH_NUMBA=0 and EASYSPYN_NUMBA=0 switch it off); SpynDynamica needs NumPy, SciPy and SymPy, and its plot extra adds Plotly for the three-dimensional pictures. The docs and test extras of the repository add the notebooks and the test suite.

# NMR: ported as Spynach (including ctps)
pip install spynach

# EPR: ported as EasySpyn simulators
pip install easyspyn

# Symbolic: SpynDynamica, the SpinDynamica port
pip install spyndynamica

# the development version, from GitHub
pip install "spynach @ git+https://github.com/ajerschow/spynach.git"

# or, for the notebooks and tests
git clone https://github.com/ajerschow/spynach.git
cd spynach && pip install -e ".[docs,test,fast]"

The first guide of each port starts from an installed package: Hilbert space for Spinach users, EPR spin systems with easyspyn for EasySpin users, Symbolic spin operators for SpinDynamica users. Nothing to install: the playground runs the three ports in Pyodide, and the Colab notebooks (EPR, NMR, SpynDynamica) or Binder run the guides' notebooks in the cloud. In a container whose CPU quota is below its visible core count, set OPENBLAS_NUM_THREADS to the quota.

How the developers of the originals are credited. Spynach and EasySpyn keep the function names of Spinach and EasySpin, so that scripts map line by line, and credit the people behind the originals where the code is: in the docstring of each translated function (help(spynach.propagator)), in a block at the top of each module, and in two generated tables of function against author, Spinach authors and EasySpin authors. Spinach lists the authors of each function in its header, and these are given by name. EasySpin's headers name no authors, so each EasySpyn function names the people who authored commits to the original file up to release 6.0.15, and any author its source names, such as John D'Errico for the Jacobian estimator; that list shows who changed a file, not who wrote which algorithm. Both lists are generated from the originals by scripts in the repository and checked by tests, and the licence keeps the original notices. SpinDynamica's source files name no authors, so SpynDynamica credits it as a whole, as its programmers page does: programmed mainly by Malcolm Levitt, with additional code and assistance by Jyrki Rantaharju (speed enhancements), Andreas Brinkmann (parallelization and powder averaging) and Soumya Singha Roy (isotope data), and with Christian Bengs, co-author of its publication, for the adiabatic tools and the S(n)/SO(3) dual pairing. Work that uses SpynDynamica should cite C. Bengs, M. H. Levitt, Magn. Reson. Chem. (2017), doi:10.1002/mrc.4642, as SpinDynamica's terms of use ask; the details are on the SpinDynamica port page. Corrections and missing names are welcome as issues on GitHub.

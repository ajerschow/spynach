Quick install

Python 3.11 or newer

# EPR: EasySpin's simulators
pip install easyspyn

# NMR: Spinach's kernel (and ctps)
pip install "spynach @ \
  git+https://github.com/ajerschow/spynach.git"

EasySpyn is on PyPI and installs Numba, which compiles its kernels; Spynach installs from GitHub and also provides ctps. More install options

Spinach port

spynach

The Spinach spin dynamics kernel in Python, stage by stage, with Spinach's names, parameters and tolerances.

Liquid-state NMR in Hilbert and Liouville space, restricted bases, anisotropic interactions with powder averaging, Redfield relaxation, magic angle spinning, COSY, NOESY and HSQC. Verified against Spinach 2.13 at every stage.

About the port First guide Run an example
EasySpin port

easyspyn

The simulators of EasySpin in Python, with EasySpin's interface: spin systems as dicts with EasySpin's field names, mT and MHz.

cw EPR of powders, crystals and solutions, least-squares fitting, ENDOR, magnetometry, slow motion, and pulse EPR (ESEEM, HYSCORE, Mims ENDOR). Verified against EasySpin 6.0.15 on every simulator.

Extras

ctps and tooling

What originated here: coherence transfer pathway selection with phase cycles, gradients and non-ideal pulses, cogwheel cycle search, relaxation pathways resolved by mechanism, and the verification tooling behind both ports.

Every pathway a sequence allows, ranked and drawn in an interactive explorer; parity harnesses and timed comparisons against MATLAB; executable guides; this browser playground.

What is here ctps guide Run an example

No MATLAB licence needed. Pip-installable packages that slot into the scientific Python stack, run on any machine, in Colab, or in this browser.

Verified, not eyeballed. Every ported stage is compared with reference data computed by Spinach or EasySpin itself, with tolerances that are stated, measured and published.

Readable kernels, ready for accelerators. The algorithms in plain Python with NumPy and SciPy, hot loops behind one backend adapter, and documentation whose code runs in the test suite.

Install

Install

Python 3.11 or newer. pip install easyspyn installs the EPR package alone from PyPI. The GitHub distribution installs spynach, easyspyn and ctps; Numba comes with both, threading the sparse kernels of Spynach and compiling EasySpyn's (SPYNACH_NUMBA=0 and EASYSPYN_NUMBA=0 switch it off); the docs and test extras add the notebooks and the test suite.

pip install easyspyn

# Spynach with easyspyn and ctps, from GitHub
pip install "spynach @ git+https://github.com/ajerschow/spynach.git"

# or, for the notebooks and tests
git clone https://github.com/ajerschow/spynach.git
cd spynach && pip install -e ".[docs,test,fast]"

The first guide of each port starts from an installed package: Hilbert space for Spinach users, EPR spin systems with easyspyn for EasySpin users. Nothing to install: the playground runs both ports in Pyodide, and the Colab notebooks (EPR, NMR) or Binder run the guides' notebooks in the cloud. In a container whose CPU quota is below its visible core count, set OPENBLAS_NUM_THREADS to the quota.

How the developers of the originals are credited. Spynach and EasySpyn keep the function names of Spinach and EasySpin, so that scripts map line by line, and credit the people behind the originals where the code is: in the docstring of each translated function (help(spynach.propagator)), in a block at the top of each module, and in two generated tables of function against author, Spinach authors and EasySpin authors. Spinach lists the authors of each function in its header, and these are given by name. EasySpin's headers name no authors, so each EasySpyn function names the people who authored commits to the original file up to release 6.0.15, and any author its source names, such as John D'Errico for the Jacobian estimator; that list shows who changed a file, not who wrote which algorithm. Both lists are generated from the originals by scripts in the repository and checked by tests, and the licence keeps the original notices. Corrections and missing names are welcome as issues on GitHub.
